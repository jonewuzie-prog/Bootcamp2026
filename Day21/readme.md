# Linux Assignment Lab Summary

In this lab, I learned how to display the current date and time, check system uptime, identify my current location in the Linux filesystem, create directories, and create files using the touch command. I practiced using commands such as date, uptime, pwd, mkdir, and touch.

I learned that an Absolute Path starts from the root directory (/) and specifies the complete location of a file or directory. A Relative Path starts from the current working directory and does not require the full path.

The most useful command was pwd because it helped me identify my current location in the filesystem. The command that was new to me was mkdir -p because it can create directories and any required parent directories in a single command.

This lab improved my understanding of Linux navigation, directory management, and file creation.
