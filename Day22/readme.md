# Linux Lab 22 Summary

In this lab, I learned how to delete files and directories in Linux using commands such as `rmdir` and `rm -rf`. I practiced removing empty directories, deleting non-empty directories, and clearing all contents inside a directory. I also learned how Absolute Paths and Relative Paths are used when deleting files and folders.

The main difference between `rmdir` and `rm -rf` is that `rmdir` only removes empty directories, while `rm -rf` removes directories and all files inside them. The most useful command was `rm -rf` because it can quickly remove directories and their contents. The command that was new to me was `rmdir`, which only works on empty directories.
